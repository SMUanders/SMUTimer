# SMU Tid på hjemmeskærmen (app-ikon)

SMU Tid kan gemmes som app-ikon på telefonen, så den åbner i fuld skærm som en
app. Den kræver stadig internet og login (ingen offline-tilstand).

## iPhone (Safari)
1. Åbn **smutimer.netlify.app** i **Safari**.
2. Tryk på **Del**-ikonet (firkant med pil op).
3. Vælg **Føj til hjemmeskærm**.
4. Tryk **Tilføj** — nu ligger "SMU Tid"-ikonet på hjemmeskærmen.

## Android (Chrome)
1. Åbn **smutimer.netlify.app** i **Chrome**.
2. Tryk på **menuen (tre prikker)** øverst til højre.
3. Vælg **Føj til startskærm** / **Installer app**.
4. Bekræft — nu ligger "SMU Tid"-ikonet på startskærmen.

Åbn appen fra ikonet, log ind, og du er i gang.
